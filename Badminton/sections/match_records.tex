
\section{Match Records}

This section presents the recorded badminton match
results, organised according to the three match formats:
Singles (1v1), Doubles (2v2), and Mixed Doubles (Mix).

Each table records the date, points scored by our team,
points scored by the opponent, and the net result.

The net result is calculated as

\[
\text{Net Result} = \text{Win} - \text{Lose}
\]

A positive value indicates that our team scored more
points, while a negative value indicates that the
opponent scored more points.

Entries with both scores absent for a particular
format are excluded. If only one score is absent,
the missing value is treated as zero.
